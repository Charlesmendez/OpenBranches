# License overrides

The `js-tiktoken` 1.0.21 npm archive declares MIT but omits its standalone license file. `overrides/js-tiktoken-1.0.21.txt` is the license from the matching [`js-tiktoken@1.0.21` source tag](https://github.com/dqbd/tiktoken/blob/js-tiktoken%401.0.21/LICENSE).

Overrides are version-specific so a dependency update fails notice generation until its published license evidence is reviewed again.
