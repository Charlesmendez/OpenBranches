# Coding-tool icons

Bundled `codex.svg`, `claude.svg`, `cursor.svg`, and `grok.svg` are from [LobeHub Icons](https://github.com/lobehub/lobe-icons), npm package `@lobehub/icons-static-svg` version **1.95.0**. The package declares MIT; the license from its matching [v1.95.0 tag](https://github.com/lobehub/lobe-icons/blob/v1.95.0/LICENSE) is retained in `LICENSE.txt`.

These assets identify recorded tool/model sources. OpenBranches is independent of these products. Icons are loaded from the app bundle; session metadata cannot specify an image URL. CSS masks apply the interface color while preserving the bundled vector shapes.
